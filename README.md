# DTS-Advanced-search
This extension allows you to analyze any part of a webpage by dragging a selection box over text or images, which is then processed by Hugging Face AI and displayed in a floating, resizable window.

# Installation
- go to the releases section
- install the source code from the latest version(for newest features and fixes)
- unpack the .zip file
- go to `chrome://extensions`
- enable developer mode(top right)
- Click load Unpacked
- click on the dist folder of the source code
- on the popup, enter your hugging face API(this video shows you how to get the API: )
- verify everything works, and you are done with the setup!
NOTE: DONT SHARE YOU'R HUGGING FACE API KEY WITH ABSOLUTELY ANYONE.
