# CHROMAC OS THEME
This extension allows you to reskin your chrome theme to look like macos TAHOE and includes some nice features to chrome.

# Installation
- go to the releases section
- install the source code from the latest version(for newest features and fixes)
- unpack the .zip file
- go to `chrome://extensions`
- enable developer mode(top right)
- Click load Unpacked
- click on the dist folder of the source code
- and you now have the amazing CHROMAC theme!
